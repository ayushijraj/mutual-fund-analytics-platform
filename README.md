# Mutual Fund Analytics Platform

## Project Overview
End-to-end Mutual Fund Analytics Platform built using Python, SQLite, and Power BI.

## Features
- Fund Performance Analysis
- Risk Analytics (VaR, CVaR, Sharpe Ratio)
- Investor Cohort Analysis
- SIP Continuity Analysis
- Fund Recommendation Engine
- Interactive Power BI Dashboard

## Tech Stack
- Python
- Pandas
- NumPy
- SQLite
- Power BI
- Jupyter Notebook

## Dashboard Pages
1. Industry Overview
2. Fund Performance
3. Investor Analytics
4. SIP & Market Trends
